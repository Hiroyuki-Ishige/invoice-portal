# sheet-name-ambiguous

シート名で決められないときは推測しない。立替費用の Excel を 2 つ (2026/10、HLAM の 1 行)。
- `two-copies`: `請求_出向者立替費用 (2)` (11,111) と `請求_出向者立替費用 (3)` (22,222)。本来の名前のシートは無い
- `exact-wins`: `請求_出向者立替費用 (2)` (11,111) と、本来の名前 `請求_出向者立替費用` (33,333)

## 受け入れ条件

1. `two-copies` は読込を断り (`error` がある)、請求書は 0 枚。
2. その `error` は英語で、候補の 2 つのシート名を両方とも挙げている。
3. `exact-wins` は読込が成功し、請求書は 33,333 の 1 枚 (11,111 ではない)。`warnings` にシート名の違いを伝える文は無い。
4. 条件の確認: 名前の近いシートが複数あっても、間違ったシートの金額で請求書ができていない。
