# expense-sheet-name

立替費用のシート名が少し違う Excel を 2 つ。中身は同じ (2026/10、HLAM 15,000、合計 15,000)。連番は 1 から (2 つ目は 2)。
- `fullwidth-copy`: シート `Sheet1` と `請求＿出向者立替費用（2）` (全角の `＿` と `（2）`)
- `spaces-fy`: シート ` 請求_出向者立替費用 FY2026` (先頭に空白、末尾に年度) と `入力`

## 受け入れ条件

1. どちらも読込は成功し、HLAM 15000 の 1 行。請求書は `HYM1AC2026-001` と `-002`。
2. どちらの `warnings` にも、実際に読んだシート名 (`請求＿出向者立替費用（2）` / ` 請求_出向者立替費用 FY2026`) を示し、名前が本来と違うことを伝える英語の文がある。
3. 関係の無いシート (`Sheet1`・`入力`) を読んでいない (行や警告にその中身が出ない)。
4. PDF のテキストに `15,000` が出る。
5. 条件の確認: シート名が少し違っても、請求書ができている。
