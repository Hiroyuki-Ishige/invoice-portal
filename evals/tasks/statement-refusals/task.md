# statement-refusals

明細の表が合わないとき、アプリが「合わない」と言い、止めるべきものだけを止めるか。架空の Excel (Claim month 2026/08) を 3 つ順に読む。連番は 601 から (3 つで続き番号)。

- `hidden-amount`: `請求_出向者立替費用` の請求先は HLAM 30,000 / HOGV 20,000 (合計 50,000)。A/C 表の Excel で**非表示**の列 `ITC sample` に 5,000 が入っている。
- `rd-broken`: 請求先は同じ。`請求_立替研究` は HOMT、Claim amount 450,000 なのに、A/C 表は 400,000 (Total 400,000)。
- `no-table`: `請求_出向者立替費用` の請求先は HLAO 8,000 だけで、A/C 表が無い。

## 受け入れ条件

1. `hidden-amount` は読込で断られ (`error` がある)、エラーは英語で、シート名 `請求_出向者立替費用` と、請求先の一覧と A/C 表の合計が合わないことを伝える。請求書は 0 枚。
2. `rd-broken` は経費の請求書 2 枚 (HLAM・HOGV、番号 `HYM1AC2026-601`・`-602`) ができ、HOMT の請求書は無い。`warnings` に `請求_立替研究` を名指しし、R&D の請求書を作らないと伝える英語の文がある。
3. `rd-broken` の 2 枚は `pages` が 2、`issueCheck` は `"ok"`。
4. `no-table` は HLAO の請求書 1 枚 (`HYM1AC2026-603`) で、`pages` は 1。`warnings` に A/C 表が無く 2 ページ目が付かないと伝える英語の文がある。`issueCheck` は `"ok"`。
5. どの請求書も金額は桁区切り付きで、PDF のテキストと通知に日本語の文字が無い (シート名を含む warnings・error は画面に出る文なので対象外)。
6. 条件の確認: 合わない Excel でも黙って請求書を作らず、作るものは発行の確認まで通っている。
